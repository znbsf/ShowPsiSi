## Requirements and remaining limits

- Windows 10 1809+ / Windows 11 on native x64; Qt packages only. ARM64/emulation
  is unvalidated. Tauri is tested separately and is not included in these downloads.
- Five pinned Microsoft release DLLs, version `14.51.36247.0` (minimum
  `14.51.36231.0`), are app-local. Setup does not download, elevate or run a
  shared-runtime installer. Windows UCRT/D3D remain OS dependencies.
- Installer remains unsigned. Checksums do not establish publisher reputation;
  do not bypass Windows security warnings on this release's behalf.
- Clean-machine offline first installation without shared VC runtime, native
  Windows file dialogs/GPU behavior, and a live future-version in-app
  download/quit/installer handoff remain unverified.
- Upgrade smoke uses a test-only former-version installer with the same app
  payload; it does not establish historical data migration.
- Portable updates require manual checksum verification, closing the app and
  extraction into a new folder. Protocol behavior remains bounded by documented
  editions/input framing, not complete receiver or standards conformance.
