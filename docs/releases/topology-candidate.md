# Signal topology release

The topology candidate shipped in
[v0.2.0](https://github.com/znbsf/ShowPsiSi/releases/tag/v0.2.0) on 2026-10-19.
Its public source, artifact identities and supported limits are recorded in
[release provenance](v0.2.0-validation.md) and [release notes](v0.2.0.md).

The workspace provides source-linked DVB, ATSC 1.0 and explicit ISDB graph
projections, bounded delivery declarations and nominal satellite candidates.
Relationships preserve original section, revision and cutoff evidence. Receiver
selection, physical transponder identity and standard-wide conformance are not
implied. See [the API contract](../TOPOLOGY_API.md).
