## Supported route and limits

- Windows 10 1809+ / Windows 11, native x64, Qt. The installer is unsigned;
  checksums do not establish publisher reputation.
- Shared Microsoft VC runtime minimum `14.51.36231.0`. Missing/old runtime setup
  offers the official prerequisite with explicit consent; Internet, Microsoft
  terms and administrator approval may be needed. Clean-machine bootstrap is unverified.
- Native Windows file dialogs/GPU and a real installed old-client download/quit/
  installer handoff remain unverified. Offscreen tests do not prove these paths.
- Upgrade smoke uses a test-only former-version installer with the same app payload;
  it does not prove a historical data migration.
- Portable updates require manual checksum verification, closing the app and
  extracting into a new folder. Tauri is not included in these Qt packages.
- Topology preserves declarations and source uncertainty; catalogue candidates
  are not verified spacecraft, RF reception or standard-wide conformance.
