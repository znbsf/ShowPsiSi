# ShowPsiSi v0.3.0

Unpublished candidate. Asset names below describe the intended packages;
Release publication and final Windows acceptance remain separate gates.

Windows Qt workbench with the shared C++/TSDuck engine. This increment adds
bounded protocol inspection and source-linked navigation to the topology
workbench. Tauri remains a separately tested alternative frontend and is not
included in these Windows downloads.

## New in this version

- Automatic NorDig interpretation from the on-wire DVB private namespace,
  preserving v1/v2 channel lists, list/country alternatives, cross-transport
  declarations, conflicts and exact sources. SDT simulcast declarations retain
  namespace evidence without deciding receiver replacement or media equivalence.
- Additional SCTE-18 EAS discovery and SCTE-35 command regressions, with explicit
  CRC, malformed and encrypted-section boundaries.
- Edition-labelled ITU-T J.94 (2016) System B section inspection, NIT/short-VCT/
  NTT/STT fields and descriptor-revised subtable queries. This does not claim a
  synchronized complete channel lineup or blanket current SCTE-65 equivalence.
- Source-linked AIT/UNT application summaries and bounded PAT/PMT-to-AIT carriage
  declarations. Shared/nonexclusive program relationships, advertised optional
  identifiers and malformed fields remain explicit.
- DSM-CC DII/DDB source cards and bounded same-PID module reconstruction. Missing
  or conflicting blocks and observation epochs are retained; hashes appear only
  for complete, conflict-free supported modules.
- Independent local DVB-I XML document sessions for the bounded ETSI TS 103 770
  V1.2.1 profile, with semantic trees, original source bytes, bounded pages and
  Qt/Web navigation in both themes. TS and XML navigation contexts remain separate.
- Hardened, pinned static Expat 2.9.0 parsing with exact upstream source inventory,
  MIT and embedded SipHash CC0 notices in both Windows distributions.
- Retains the reviewed private-namespace termination and malformed long-section guards,
  preserving raw evidence rather than fabricating semantic objects.

No HbbTV execution, firmware eligibility or installation, BIOP object extraction,
decompression, media playback, remote DVB-I fetching, RF reception or full
standard/receiver conformance certification is claimed. Protocol coverage is
bounded by the recorded source edition and supported input framing.

## Requirements and important limits

Windows 10 1809 (build 17763) or newer, or Windows 11, on native x64 hardware.
ARM64/emulation is not validated. The app-local candidate includes the matching
Microsoft release x64 runtime 14.51.36247.0 (minimum 14.51.36231.0), including all
five reviewed DLLs required by Qt/core. Setup does not download, elevate or run
a shared-runtime installer. Portable Launch Qt.cmd checks the local copies and
explains missing/old/corrupt files; re-extract a verified package rather than
copying DLLs from another program. Windows UCRT/D3D remain OS dependencies.
Microsoft-only terms are retained alongside MIT/Qt LGPL notices; runtime servicing
comes through reviewed ShowPsiSi updates. The exact-inventory engineering
[distribution review](../PORTABLE_LICENSE_REVIEW.md#hosted-runner-distribution-basis)
is complete; its hosted REDIST interpretation is an explicit inference. Native
Windows/final-payload acceptance remains a separate publication gate.

The installer is unsigned. A correct SHA-256 confirms the published file's
identity; it does not establish publisher code-signing or SmartScreen reputation.
Do not bypass Windows security warnings on this release's behalf.

Installed Qt builds can download a newer stable installer after confirmation,
verify it, and ask separately before launching its visible setup wizard and
quitting. Save/export work first. Portable builds offer the matching official
ZIP in the browser and require manual checksum verification, closing all app
windows, and extraction into a new folder. Portable updates do not overwrite
files or silently change to the installer edition.

## Verified scope

Publication requires the exact main source's successful five-job CI run, Windows
engine/Qt/updater tests, relocated portable/runtime checks, exact dependency and
source-license inventory, portable launcher prerequisite probes, and actual
installer upgrade/reinstall/uninstall smoke in a Unicode/spaces path. The smoke
covers settings/shortcut/payload identity, downgrade/live-process rejection,
installed core export/readback and Qt/core startup. The former-version upgrade
fixture uses the same application payload with a test-only 0.0.0 installer;
it does not prove a historical application data migration.

Clean-machine offline first installation without any shared VC runtime,
native Windows app file dialogs/GPU behavior, and a live future-version end-to-end
in-app upgrade remain unverified. Hosted-runner and offscreen passes do not prove
these cases. The program is not an RF receiver or a blanket broadcast-standard
conformance certification. Preserve a known-good copy and important exported data.
