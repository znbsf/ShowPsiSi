Qt 6.7.3 source-derived notice collection

This retains all attribution records under src/ for qtbase, qtdeclarative and qtsvg, their referenced license/copyright files and each source module LICENSES directory. It is a conservative superset covering optional features and other platforms, not a claim every component is shipped on Windows.

The intended Qt runtime route is LGPL-3.0 with GPL-3.0 text included as required. FreeType uses its FTL alternative. BLAKE2 may use CC0. Alternative license texts are retained verbatim; their presence does not select the alternative. Unrelated GPL-only tools/modules are not authorized for inclusion by this collection.

source-attributions.json records exact official source archive hashes (checked against publisher .sha256), attributions and copied-file hashes. Actual deployed Windows files must be mapped to covered module families. External runtime payloads, e.g. opengl32sw.dll or d3dcompiler_47.dll, require separate review.

These notice files are not complete corresponding source by themselves. Accompany the binary with the verified matching source archives and source/build/replacement information using the selected distribution mechanism. Do not mark the bundle review complete until those materials and the actual deployment inventory are checked.
