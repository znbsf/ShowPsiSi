# ShowPsiSi v0.1.0

Windows Qt workbench with the shared C++/TSDuck engine. Inspect PSI/SI tables,
services, descriptors and their source evidence, compare historical snapshots,
and preview safe edits before exporting. Qt About / Updates provides an explicit
manual check against this official repository. Tauri remains a separately tested
alternative frontend and is not included in these Windows downloads.

## Downloads

- ShowPsiSi-0.1.0-windows-x64-setup.exe: current-user installation with Start Menu
  shortcut, upgrade/reinstall guards and an uninstaller that keeps user settings.
- ShowPsiSi-0.1.0-windows-x64-portable.zip: no-install Qt/core folder. Extract to a
  new directory and start Launch Qt.cmd. Do not overwrite a running copy.
- SHA256SUMS: SHA-256 for both downloads. Check the saved file before using it.
- release-provenance.json: exact source/CI/artifact identities and validation scope.

## Requirements and important limits

Windows 10 1809 (build 17763) or newer, or Windows 11, on native x64 hardware.
ARM64/emulation is not validated. The required Microsoft x64 VC runtime minimum
is 14.51.36231.0. Setup checks it and, only with explicit consent if it is missing
or too old, downloads the exact verified official Microsoft prerequisite.
That first installation may require Internet access, the Microsoft license
acceptance dialog, and administrator confirmation through UAC. This is not a
fully offline installer. Cancellation, failed verification, UAC refusal or a
restart-required result stops ShowPsiSi installation. Silent setup never installs
that prerequisite. Portable Launch Qt.cmd checks the runtime and explains what
is missing; it does not download or install it.

The installer is unsigned. A correct SHA-256 confirms the published file's
identity; it does not establish publisher code-signing or SmartScreen reputation.
Do not bypass Windows security warnings on this release's behalf.

Installed Qt builds can download a newer stable installer after confirmation,
verify it, and ask separately before launching its visible setup wizard and
quitting. Save/export work first. Portable builds offer the matching official
ZIP in the browser and require manual checksum verification, closing all app
windows, and extraction into a new folder. Portable updates do not overwrite
files or silently change to the installer edition.

## Verified scope

Publication requires the exact main source's successful five-job CI run, Windows
engine/Qt/updater tests, relocated portable/runtime checks, exact dependency and
source-license inventory, portable launcher prerequisite probes, and actual
installer upgrade/reinstall/uninstall smoke in a Unicode/spaces path. The smoke
covers settings/shortcut/payload identity, downgrade/live-process rejection,
installed core export/readback and Qt/core startup. The former-version upgrade
fixture uses the same application payload with a test-only 0.0.0 installer;
it does not prove a historical application data migration.

Clean-machine first installation, the actual missing-runtime download/UAC flow,
native Windows app file dialogs/GPU behavior, and a live future-version end-to-end
in-app upgrade remain unverified. Hosted-runner and offscreen passes do not prove
these cases. The program is not an RF receiver or a blanket broadcast-standard
conformance certification. Preserve a known-good copy and important exported data.
