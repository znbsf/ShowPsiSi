# ShowPsiSi v0.3.1 release validation

## Candidate checkpoint, 2026-10-20 UTC

This is a pre-publication record, not proof of a published release. The currently
verified public release is [v0.3.0](v0.3.0-validation.md); its notes and provenance
are preserved unchanged.

The v0.3.1 candidate combines the existing UI refinements with responsive-analysis
work. Local development started from UI PR #27 head
`e80dabb692ca055eaf735d170976ab6787f624c5`, plus an uncommitted feature patch.
That base SHA is **not** the final tested or published v0.3.1 revision.
The final source/tag, main-push CI run, publication run, public assets and byte
readback are not yet established and are intentionally not populated here.

Product versions are 0.3.1 in canonical CMake, Tauri configuration, Cargo manifest
and the application package entry in Cargo.lock. Dependency versions, including
Qt 6.7.3, remain unchanged. The publisher derives its version and asset names from
the trusted checkout's CMake version and requires matching reviewed release notes.

## Available local evidence

These earlier development checks used a dirty patch, not a frozen release SHA:

- Linux strict core aggregate: 634 discovered tests, 633 passed and one existing
  optional real-recording test skipped because its separately sourced input was
  absent. No failures/errors were reported in that run.
- Real-engine Chromium workbench: 76 tests passed; shared scan/search helpers:
  3 tests passed. Chromium is not native Windows Tauri/WebView2.
- Final local versioned Qt aggregate: 137 tests, 135 passed and two failed
  with unchanged source/binary identities. The two failures were 25-second
  missing-report timeouts in legacy flows; all 10 new analysis tests passed.
- PR #28 run `39418321685` tested merge checkout
  `ee598433734b2bcf77f1292cb28d0cd2d7d0629f`, tree
  `46bd5386f6e1b74427710ecf272a32b795136838`. Four jobs passed, including
  Linux Qt 137/137. Windows Qt had 136 passes and one WinError 32 cleanup error
  deleting an inherited log file; subsequent packaging gates were skipped.
  A tests-only owned-process-tree cleanup correction is awaiting fresh CI.
  These are PR checks, not the required successful final main-push gate.
- Intermittent approximately 0.5–2.1-second GUI stalls and protocol/navigation
  timeouts remain unresolved findings. The tooltip experiment is excluded.
- The detailed measurement method, synthetic input limitations and development
  evidence belong in [responsive-analysis validation](../RESPONSIVE_ANALYSIS_VALIDATION.md).

## Required delivery evidence

Before reporting publication, replace this candidate status with verified facts:

1. Record the full final source/tag SHA and tree, and distinguish any earlier
   dirty-tree tests from tests of that exact source.
2. Record the successful five-job **main-push** CI run for that source, including
   Windows engine/Qt/updater, relocation/app-local runtime, license/source and
   installer lifecycle/payload gates. PR-head or PR merge-test checks cannot
   authorize publication of a different main revision.
3. Record the release-publication run and official release page only after they
   exist. Verify the tag, release body, latest endpoint and provenance all name
   the same source.
4. Download and verify the three versioned package/source assets, SHA256SUMS and
   release-provenance.json. Record their actual sizes/hashes and the portable
   manifest hash; do not reuse v0.3.0 values or predict future identities.
5. Verify published metadata compatibility with the existing update parser.
   Keep parser compatibility distinct from a real Windows in-app upgrade.

These are required checks, not recorded successes. Local contract tests use
inert fixtures and cannot establish Windows packaging or public asset identity.

## Persistent limitations

- Qt Windows x64 packages only; Tauri is tested separately and not bundled.
- Installer remains unsigned; checksums are not independent publisher trust.
- Clean-machine offline first installation, native Windows file dialogs/GPU,
  real HDD throughput and the user's recordings are not validated locally.
- A live future-version download/quit/installer handoff and historical
  application data migration remain unverified.
- Partial previews are read-only, with explicit coverage gaps. Pagination does
  not imply bounded total memory or that all Qt responsiveness issues are fixed.
