REBUILDING AND REPLACEMENT
Extract the source archives and follow their included build documentation using
an x64 MSVC-compatible toolchain and the recorded Qt build-feature information.
Build shared libraries, preserve the Qt 6 ABI expected by this application, and
build the corresponding modules/plugins. The application's source checkout
contains its CMake and Windows packaging scripts. Those scripts record the
windeployqt invocation and qt.conf deployment layout.
With the application closed, back up bin/, then replace the appropriate Qt DLLs
and matching plugin/QML files there with your compatible rebuilt versions.
Qt libraries remain dynamically loaded; there is no package-manifest signature
check that prevents using modified libraries. Reverse engineering for debugging
modifications to Qt is permitted. The application's MIT source is available too.
