# ShowPsiSi v0.3.1

Windows x64 Qt workbench with the shared C++/TSDuck engine. This patch combines
the editor-style UI refinements with compact analysis transport, in-session
pause/resume and bounded read-only previews. It is not a claim that all large-file
GUI stalls are fixed. Tauri remains a separately tested alternative frontend and
is not included in these Windows downloads.

## New in this version

- Lightweight scan progress and compact terminal responses, followed by
  revision-bound, bounded result pages instead of repeatedly transferring the
  whole analysis state. Complete result hydration preserves all-record search,
  table/group counts and history. The legacy API response mode remains available.
- Pause and resume continue the same open analysis session, retaining parser,
  framing and continuity state. Cancel still discards unfinished analysis.
  Pause is not a durable checkpoint and cannot resume after application exit.
- Full-file analysis, prefix and explicit packet-range previews, and distributed
  contiguous-window sampling, including a 10% preview. Coverage records the
  packets and intervals actually scanned. Partial results remain read-only:
  missing tables in skipped regions are unknown, not evidence of absence;
  editing/export and unsupported cross-gap comparisons are guarded.
- More restrained light/dark workbench styling, compact inspector summaries,
  grouped scan options, clearer disabled-action reasons, persistent warnings
  and errors, and navigable service/table/issue statistics.
- Section metadata and lookups are separated, with structured values, sources
  and expandable raw evidence. Structure reference shortcuts only appear for
  supported standard fields with an unambiguous available target.
- Qt Hex ASCII output, keyboard-accessible density and A/B timeline controls,
  recent-file selection, shortcut help, and Ctrl+K command/identifier navigation.
  Reference jumps and identifier searches retain return navigation.

The SDK and dependency pins are unchanged, including Qt 6.7.3 and
TSDuck 3.45-4798. Existing bounded protocol inspection and evidence/provenance
rules remain in force; this patch does not extend the claimed standards coverage.

## Performance and known issues

Compact transport reduces repeated serialization and large wire messages, but
the frontends still hydrate complete in-memory result models. This is not
disk-backed indexing or a bounded-total-memory guarantee. Qt still decodes
bounded page JSON on the GUI thread.

Pre-release Linux testing observed intermittent approximately 0.5–4.4-second Qt
GUI stalls and protocol/navigation timeouts. Targeted passing reruns do not
establish that these failures are resolved, and this patch makes no general
smoothness or large-file performance guarantee. The experimental tooltip
optimization was excluded from this release candidate.

Synthetic transport measurements do not establish throughput on a mechanical
disk, behavior on the user's recordings, or native Windows/WebView2 interaction.
A 10% sample is not a completeness guarantee or a guaranteed tenfold speedup.
Keep the input unchanged while scanning or paused. Detailed inspection becomes
available after analysis/preview completion, not while the parser is paused.

## Requirements, updates and acceptance boundaries

Windows 10 1809 (build 17763) or newer, or Windows 11, on native x64 hardware.
ARM64/emulation is not validated. The app-local packages retain the five reviewed
Microsoft release x64 runtime DLLs, version 14.51.36247.0 (minimum 14.51.36231.0).
Setup does not download, elevate or run a shared-runtime installer. Windows
UCRT/D3D remain OS dependencies. Microsoft-only terms and the existing MIT/Qt
LGPL notices, source instructions and replacement rights remain with the package.

The installer is unsigned. SHA-256 verifies file identity, not independent
publisher code-signing or SmartScreen reputation. Do not bypass Windows security
warnings on this release's behalf.

Installed Qt updates require separate confirmation to download and to launch the
visible setup wizard and quit. Save/export work first. Portable updates require
manual checksum verification, closing every app window and extraction into a
new folder; they never overwrite the current folder or silently switch editions.

Publication requires the exact final main source's successful five-job hosted
CI run, Windows engine/Qt/updater checks, relocated app-local runtime validation,
the exact reviewed dependency/source/license inventory, paired corresponding
sources, and installer install/upgrade/reinstall/uninstall smoke with matching
payload identities. Earlier commits, local passes and targeted reruns do not
replace these gates.

Clean-machine offline first installation without a shared VC runtime, native
Windows app file dialogs/GPU behavior, real mechanical-disk performance, the
user's own recordings, and a live future-version end-to-end in-app upgrade remain
unverified for this patch. The former-version installer smoke uses a test-only
0.0.0 installer around the same payload; it does not prove historical application
data migration. Keep a known-good copy and important exported data.
