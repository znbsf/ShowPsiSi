## Independent public readback and client metadata

All four public browser-download assets were downloaded without credentials
through the official GitHub release CDN and matched the sizes/hashes above.
The production Qt `ReleaseMetadata` parser accepted actual latest-release JSON
and the downloaded checksum bytes: installed `0.1.0` reports up-to-date, and a
parser-only earlier-version fixture selects the exact installer/portable assets
and their hashes. That fixture does not execute an installer or claim a real
upgrade handoff.

The cloud's direct unauthenticated latest-API request reached GitHub's shared-IP
rate limit (`403`, remaining `0/60`), so the parser's actual API JSON was retrieved
through the existing GitHub connector. This route is explicit, not reported as
an unauthenticated API success. Independent asset downloads were unauthenticated.
Existing compiled updater regressions confirmed that HTTP 403/429/500 produce an
error with retry/release-page guidance, rather than an up-to-date result.

## Supported route and remaining limits

- Windows 10 1809 or later / Windows 11, native x64, Qt workbench. The installer
  is unsigned; hashes do not establish publisher signing or SmartScreen reputation.
- VC runtime minimum `14.51.36231.0`. When missing/old, setup offers the official
  Microsoft prerequisite with explicit consent; first install may need Internet
  and UAC. Hosted tests used an existing runtime, so clean-machine prerequisite
  bootstrap is not claimed.
- Native Windows dialogs, GPU behavior, and a real installed older version's
  future-version download/installation handoff remain unverified. Qt offscreen
  automation and metadata parsing do not establish those outcomes.
- Portable ZIP updates use the official release page, manual checksum verification
  and new-folder replacement. Tauri is not included in this Qt installer and does
  not inherit its updater acceptance.
